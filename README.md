# 🚂 Rail Yatra (Indian Railway Nostalgia)

**Rail Yatra** is an immersive, cinematic web experience designed to recreate the profound nostalgia of an Indian Railway Sleeper Class journey. Featuring dynamic time-of-day visuals, ambient sound mixing, and built-in travel music, it transports you straight to a window seat on a moving train.

## ✨ Features

- 🌅 **Dynamic Time of Day:** Watch the passing landscape change across Golden Hour, Midnight, Morning Dawn, and Monsoon.
- 🎚️ **Ambient Sound Mixer:** Fully customize your journey's background noise. Mix the volume of the Train Rhythm, Ceiling Fan Hum, Window Breeze, and the iconic "Chai गरम" vendor calls.
- 🎵 **Integrated Travel Music:** Pre-configured to stream classic Bollywood travel and journey anthems via YouTube in the background. 
- 📝 **Nostalgic Poetry:** A built-in diary widget that cycles through beautiful Hindi and Bengali poetic musings about train travel.
- 📱 **Fully Responsive:** Gorgeous glassmorphic UI that works perfectly on desktop and mobile.
- 📶 **Offline Support:** Includes an offline fallback page so the journey never completely stops.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- npm or yarn

### Installation & Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imchiraghere/rail-yatra.git
   cd rail-yatra
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the URL provided by Vite (usually `http://localhost:5173`).

## 🛠️ Built With
- **React 18** (Vite)
- **Tailwind CSS v4** (For stunning glassmorphic UI and animations)
- **Lucide React** (Icons)
- **Howler.js** (For seamless audio mixing and cross-fading)
- **react-youtube** (For headless YouTube music streaming)

## 🎨 Design Philosophy
The goal was to build more than just an app; it is a **mood**. The UI employs deep, rich colors with glassmorphic overlays to ensure the passing train window always remains the focal point.
